PROJECT: Scientific Literature Trend Finder
TARGET USER: Non-technical PhD Students
EXECUTION TIMEFRAME: 1 week

1. Scope:
   - Build a Python script that queries the free PubMed API for 1 keyword (e.g., "HIV phylogenetics").
   - Fetch the top 5 recent abstracts.
   - Pass the abstracts through a free LLM (OpenAI API free trial, Claude, or local Ollama) 
     to extract: (a) 2-bullet summary, (b) study location/country, (c) sample size (if present).
   - Display the results in a minimal Streamlit web app with a single search bar.

2. Deliverables:
   - A public GitHub repository link containing:
     * Clean, documented Python code.
     * A simple README with instructions on how to run it.
     * A 1-minute screen recording or screenshot of the working Streamlit UI.

3. What We Are Evaluating:
   - Code cleanliness and structure.
   - Proper handling of API calls and missing data.
   - How robustly they enforce structured LLM outputs (e.g., Pydantic/JSON).
